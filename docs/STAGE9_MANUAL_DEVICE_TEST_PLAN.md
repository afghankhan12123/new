# Owner manual device test plan — NE2211

These checks are for the owner. They were not performed during implementation. Install the APK identified in the handoff and record the full workflow plus any displayed error detail.

1. **Timeline:** Import three distinct videos and a photo. Scroll/fling, scrub both directions, play/pause repeatedly, pinch zoom around different anchors, trim, split, reorder, duplicate/delete and Undo/Redo. Check that the requested frame lands and that photo thumbnails appear. Repeat with a long clip at high zoom.
2. **Transitions:** Start with untrimmed adjacent videos. Review the exact handle proposal, change duration and Apply. One Undo should remove the join and restore both trims; Redo should restore all three. Play/scrub before, through and after the join. Add several further joins; remove/change one. Exercise all thirteen types, including exact start/end boundaries, black/white midpoint, and fractional-speed clips. Check that hidden transition sources do not replace primary video after a join ends.
3. **Text:** Add one caption, type with the keyboard visible, Apply, tap the existing caption and edit it. Confirm exactly one ID/layer persists. Drag, corner resize, rotate and pinch. Add another caption, Cancel, then Undo/Redo: canceled text must not reappear. Verify font, size, color, alignment, stroke/shadow/background, timing, retained animations and save/reopen.
4. **Stickers/PiP:** Add different-aspect stickers and a video/photo PiP. Tap each to select, drag, corner resize, pinch/rotate and snap to center. Compare handle bounds with visible content. Change opacity/fit/crop where offered, duplicate/delete and change layer order. Check live updates paused and playing; check Undo/Redo.
5. **Effects/keyframes:** Stack, reorder, duplicate, disable and remove effects. Exercise nine adjustments, eight image effects and seven presets. Cancel a draft then Undo: canceled changes must not be recorded. Add intensity keys on a later clip, navigate/edit/remove them and compare Linear/Hold/Smooth. Split/head-trim a keyed clip and inspect animation continuity.
6. **Masks/chroma/blend:** Exercise rectangle, rounded, ellipse, gradient and regular 3–8-sided polygons; move/scale/rotate/feather/invert. Add multiple distinct mask keys and confirm earlier values survive later keys. Try green/blue/custom key colors, tolerance/softness/spill/alpha and all thirteen blend modes. Add opacity keys to a PiP that begins after project zero.
7. **Audio:** Add music and voiceover. Check alignment, volume, source automation, all five fade curves, EQ, ducking, panning and supported speeds. Apply/remove transitions and confirm standalone audio placement stays unchanged. Compare preview/export AV sync at start, joins and end.
8. **Export:** Export 720p and 1080p with transitions, text, stickers, PiP, effects and music together. Try available frame-rate/quality settings. Progress must move beyond 0%; inspect actual completion metadata and open each MP4 externally. Check dimensions/orientation, duration, first/last frames, transition pixels, overlay positions/scales and audio sync. Save through gallery and Files.
9. **Cancellation/recovery:** Cancel export, retry with a fresh session, return to the editor and seek/play. Background/foreground, enter/exit fullscreen, return home and reopen the saved project. If a preview error appears, use Retry Preview and verify no edit/history is lost. Repeated automatic retry must stop after the bounded attempt.

Report project/media types, selected profile, exact error text and the point in the recording where it occurred. A build success is not a runtime pass. Keep original projects/media; there is no need to wipe application data.
