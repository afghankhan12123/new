## New versus preserved work

New: persistent boundary/replay preview, delayed-child reset gating for videos/images, correct PiP-only shared primary lifetime, bounded newest-target reset scheduling, speed/transition recalculation and explicit shortening choice, full speed Undo snapshot, exception-safe history transfer, transition default/range and fine PiP rotation. Prior dirty Stage 9 fixes to text shaping, canvas, transition interval selection, watchdogs, imports, command identities and export UI state are preserved in the new APK.

All production changes and selected regression sources were compiled. Regression tests were not executed; no connected tests/benchmarks/emulator/device installation were run. All visual/sound/cadence/latency/persistence claims remain limited to the described source contracts until owner verification. Remaining missing capabilities above are explicit product gaps; this delivery does not claim complete CapCut parity.
